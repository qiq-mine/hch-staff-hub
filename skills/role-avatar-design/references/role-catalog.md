## Technical Specifications:
* **Standard Resolution**: `256 x 256` pixels (lossless optimized PNG)
* **Master Resolution**: `1024 x 1024` pixels
* **WebP Optimized**: `256 x 256` pixels (~8-10KB per asset)
* **Color Mode**: sRGB, 8-bit
* **Target Container**: Rounded squircle (`rounded-2xl` or `rounded-full`) in UI profile cards and member lists.
